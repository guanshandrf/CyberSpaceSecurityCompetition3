# 威胁模型（P0 设计基线）

状态：SDK 0.9.0 提供 Gate0/1/2；P6 已将 LangGraph 演示接入严格受控通道，基线独立保留。

## P6 框架边界

P7 演示层另有脱敏展示历史和审计 API，前端以文本插值显示内容。审计开关不提交给后端，
原参数不进入审计投影；未知标识使用 HMAC，原因和策略白名单化。跨源 POST 和非本地 Host
拒绝，默认仍为本地无认证演示。重启后历史只读，不恢复可执行会话或重发工具调用。
脱敏只能覆盖已知规则/显式配置值，普通私人文本仍需用户自行控制；详见 `docs/web-chat.md`。

P6 加固后，过期注册只有可信后端传入当前权限、重新经过 Gate0 才能恢复；撤销状态不被
到期清理或慢检查覆盖。非法模型调用不执行，保留脱敏拒绝审计和可关联的错误消息；缺失/
重复/不可编码 ID 在整批执行前拒绝，失败轮次不保留未配对历史。P2 协议保持不变。
检测增强仅为中英文组合意图规则，48 条人工对照语料不是通用语义能力或外部 Benchmark 证明。

受保护图只绑定 Adapter 包装，所有工具结果（含错误）经过 Gate2 后成为 ToolMessage；
原始结果不返回模型/HTTP/SSE。包装的同步、异步、直接调用均走相同执行通道，
模型/客户端不能指定可信上下文、注册摘要或 Guard 开关。后端按会话保留执行器，
每轮重建图不重置预算与防重放；撤权通过 update_context 原子发布。
注册使用独立生命周期 trace，调用/结果使用本轮 trace 与模型 tool_call_id；审计 HMAC 关联。

保护仅覆盖接管的同步工具；不能拦截任意 Python 反射、持有原始 handler 的受信后端、
框架内置/托管工具、子 Agent 或另建 ToolNode。演示仍无身份认证、会话持久化和审批 UI；
只供本地单用户实验，不能直接面向远程不可信用户部署。规则漏报/误报、已产生副作用、
恶意本机进程和单进程预算的限制仍存在。P8真实18次DeepSeek仅验证选定官方案例/组件重放，不能扩展为通用保护效果或完整Benchmark成绩。

## P4 结果边界

P5 另提供配置 ToolRegistry 的严格执行通道：拒绝/待审批/更新/过期/撤销均影响 Gate1，
最终核销检查注册代次。摘要绑定安全配置与声明元数据，不能证明 Python 代码安全。
无 registry 的 P3 兼容入口不宣称 Gate0；P6 保护路径必须使用严格通道。详见 docs/gate0.md。

ResultHandler 将原始结果和安全结果分离，BLOCK 不交回原文，SANITIZE 仅交回替换内容。
正常/异常/非法输出都能经过结果检查；检测/脱敏/审计故障默认阻断。安全来源标记不把
工具内容升级成可信指令。规则检测并非完整语义判断，具体范围和残留风险见 docs/gate2.md。

## P3 当前边界

Gate 1 硬性拒绝优先于可替换策略；执行器绑定可信工具配置、完整审批指纹，在锁内核销
单进程会话预算和调用/event ID。BLOCK 或未批准 REVIEW 的受控工具执行计数为零。
路径遍历、目录联接、硬链接、非法参数、伪造上下文、插件异常、并发重试及审计泄漏由
tests/p3 覆盖。审计采用字段白名单和标识 HMAC，不记录参数、工具结果或异常正文。
这仅覆盖经过该执行器的同步调用；P6 Adapter 受保护路径才将其扩展到演示 Agent。
Schema 仅支持明确子集，未知关键字拒绝配置；不支持任意第三方 Schema。
任意 Python 插件/handler 是受信代码，SDK 不能隔离它；文件系统外部竞态、恶意本机进程、
工具自行越权、跨进程/重启后重放和核销不在 P3 保证内。根目录祖先须由主机保护。
审计失败前置阻断；后置失败不能撤销工具副作用。完整 API/限制见 docs/gate1.md。
P3 安全加固将检测/策略移出执行器锁，按会话串行化最终检查，仅短时锁住全局计数与索引。
审批记录有全局/会话容量、创建窗口限流、Token 直接索引与过期回收；容量满时 BLOCK。
后端通过 update_context 发布撤权，执行点复核最新权限与修订号；不修改 P2 协议。
Windows CONIN$/CONOUT$、COM/LPT 上标数字和主名尾空格变体在词法层跨平台拒绝。

## P2 契约边界

只接收三类严格、带版本和关联 ID 的事件，拒绝额外字段、非法 JSON/超限内容、不适用
Gate 的动作；关联检查不授予执行权限。可信上下文必须通过可信后端入口构造，拒绝普通
JSON 伪造来源标记，并冻结身份/权限/预算。此入口不是认证或签名，不能从不可信输入直接
调用；恶意 Python 代码在同一进程内不属于此信任边界的防护目标。
嵌套 JSON 仍可变，解析/关联入口重新验证字段；完整防重放、参数绑定、授权、硬拒绝优先
及执行前原子检查属于 P3。模型错误字符串隐藏输入，结构化 errors() 仍须关闭 include_input。
模型序列化不等于脱敏，payload 仍可能敏感，禁止直接记录到日志；P3 审计只持久化白名单
字段，内容 Redactor 仍属于 P4，契约本身不执行脱敏。
P1 真实只读工具冒烟通过，不延伸为 Guard 防护证明，也不是 Benchmark 分数。

## P1 当前边界

演示 API 仅供本地单用户实验，默认关闭无 Guard 基线；请求不能设 Provider、凭据或开关。
Fake 默认不构造网络客户端；真实 DeepSeek 需独立开关/密钥，并受每会话/每进程调用、
输出 token、超时和无自动重试限制。计数不是账户级预算，重启重置，输入 token 仍有费用。
read_file/write_note 在工具自身执行静态路径/链接检查、大小限制和独占创建；
不把此类工具沙箱等同于 Gate 1，不宣称受 SDK 保护。测试使用仓库内隔离文件，
真实目录联接/硬链接只连接受控 fixtures。常规外网/回环连接仍被测试拦截，
仅标准库 socketpair 所需的本地 IPC 允许，以支持 Windows asyncio/TestClient。
执行会话内存不持久化、没有认证，不能面向不可信远程用户部署；提示注入仍可操纵基线，
工具结果未过 Gate 2；本机恶意进程竞态、断连/重试和副作用回滚不在 P1 保证范围。
Provider 错误和验证错误只返回通用代码/字段位置，不回显服务端异常或原始错误输入。
除一次真实只读工具冒烟外，真实 API 异常/安全效果与所有 Gate 安全不变量仍未验证。

## 资产、对手与信任边界

资产：用户授权资源、工具副作用、会话上下文、API Key、调用预算、审计内容、实验可信度。
对手可能控制工具描述、工具返回、网页/文件正文、部分调用参数或模型输出；不能将这些
数据等同于可信后端的身份、任务授权与审批。后端权限存储和受控执行器属于信任计算基。
主机、后端或第三方原生代码已被完全攻陷不在本 SDK 的防护承诺内。

主要边界：用户/模型 → 后端可信上下文；框架工具 → Adapter/Executor；外部内容 →
Gate 2 → 下一轮模型；服务端审计 → 浏览器；公开评测框架 → 隔离实验环境。

| 威胁/攻击路径 | 预期控制 | 必须验证的性质/阶段 |
| --- | --- | --- |
| 恶意工具描述、声明过度权限、更新后偷换元数据 | Gate 0 注册/更新准入，绑定摘要和来源 | 未批准不暴露；版本变更重审；P5 |
| 越权路径、非法参数、预算耗尽 | Gate 1 + 可信资源范围 + Schema + 预算 | BLOCK 时真实工具执行数为零；P3 |
| 模型自报管理员身份、低风险分覆盖权限拒绝 | 后端构造 SecurityContext，硬性拒绝优先 | 伪造身份无效；P2/P3 |
| 策略异常、缺失上下文、未批准 REVIEW | 默认拒绝、可信审批、执行前重验 | 无副作用；P3 |
| 并发/重试复用旧授权、TOCTOU | 绑定本次调用、工具版本、参数和预算，原子核销 | 不复用旧 Decision 绕过；P3/P9 |
| 结果中注入系统指令、冒充用户/角色 | Gate 2 来源标记、规则/可替换 Detector、结果处理器 | 原文不在 BLOCK/SANITIZE 后进入 LLM；P4 |
| 工具错误响应包含注入或密钥 | 所有结果（含错误）经过 Gate 2 和脱敏 | 错误路径不绕过；P4 |
| 同时暴露原始工具引用、托管工具旁路 | Adapter 统一入口和受控工具集合 | 明确覆盖范围，禁止夸大全工具保护；P6 |
| 审计/前端泄密、XSS、隐藏审计关闭 Guard | 服务端脱敏、文本渲染、展示与执行分离 | UI 不显示原始敏感内容；P7 |
| 恶意样例产生真实副作用或外发 | 隔离 fixtures、模拟工具、离线 Fake LLM、显式真实运行与预算 | 普通测试无 Key/无网络；P1 起持续 |
| Mock 冒充真实模型或 Benchmark 成绩 | 原始结果、版本/种子/任务 ID 与运行日志留存 | 外部未运行写未验证；P8 |

## P0 已验证范围

默认 SDK 安装依赖不包含 Web/Agent/Benchmark；静态依赖检查及禁止框架导入的隔离进程
可以导入已安装 SDK。pytest 在仓库临时目录内运行并阻止常见 Python socket 连接/DNS；
前端挂载测试拒绝 fetch/XHR/WebSocket；检查脚本移除凭据环境变量，npm 检查命令离线。
`.env.example` 不含密钥，`.gitignore` 忽略真实环境文件及本地缓存。

这些措施用于常规测试隔离；不能拦截任意第三方进程、原生扩展或所有网络 API，
也不是恶意代码沙箱。首次安装依赖需要受控网络；供应链安全不由锁文件完全保证。

## 残留风险和待验证能力

P0 建立骨架，P3–P6 已实现并离线验证授权、审批、预算、三 Gate 与 LangGraph 接入。
P9第二适配器已接入纯Python循环，共用同一SDK三Gate；不能将离线端到端测试扩展为真实模型或全框架保护声明。
静态元数据不能证明第三方 Skill/工具代码安全，路径限制还需处理链接、规范化和竞态。
Gate 2 不能撤销工具副作用；规则检测有误报/漏报；不承诺彻底消除提示注入。
真实 API 和 Benchmark 后续必须设置预算、保护凭据、固定实验版本并保留可复现原始判定。


## P9 交付边界

SimpleAdapter仅接收模型名称/参数/调用ID，后端拥有权限、注册摘要与审批；工具metadata为副本，
不暴露handler，只回送safe_event。注册续期重审且不重置预算；撤权经过Executor最终复核。
非法调用、重放、预算、并发、过期/拒绝审批、Gate故障均有独立回归。P2公共协议保持1.0。
P8规则存在物理访问类注入漏报，阻断污染结果会损失合法任务可用性；小样本攻击基线已失败，
不能归因Guard降低攻击成功率。MSB原生MCP及τ³完整奖励、生产SLA、跨系统实际验证未完成。

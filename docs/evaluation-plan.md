## 运行授权与可复现记录

普通测试用隔离 fixtures/Fake LLM，真实 DeepSeek、下载与评测均须独立显式启用；
P0 不提供真实运行入口。未来入口需要预算上限、超预算中止、凭据环境变量、默认关闭，
危险工具使用沙箱/模拟执行，禁止真实泄漏或破坏。锁定模型名、API 参数、温度/种子
（如支持）、框架 commit、任务 ID、攻击输入摘要、重复次数、预算与执行时间。
凭据不进入日志，私有样例不进 Git；对受控公开攻击样例保留必要可复现引用。

## 对照与指标

同一任务/攻击/环境状态上比较隔离 baseline、规则版、完整 AgentGuard 和必要的单 Gate
消融；不复制 Guard 规则实现。分别计数模型主动拒绝和 Guard 阻断；Gate 1 阻断必须能
对应执行计数为零的证据。记录原始判定与失败样例，不能只存汇总分数。

- ASR：攻击成功数/有效攻击试验数；明确分母、无效/失败/超时与缺失判定处理。
- 正常任务成功率：成功正常任务/有效正常任务；误拦截率单独记录并说明标注方法。
- 延迟：同任务基线/防护的分布和额外延迟，说明重复次数与测量边界。
- Token/API 成本：有官方 usage/价格证据时统计；缺失标记 unavailable，不能当作 0。

原始 JSON/CSV 至少包含 benchmark/version、run_id、task_id、attack_id、模式、模型参数、
原始判定、Guard 动作、真实工具执行计数、延迟/usage/成本（可空）、异常与排除原因。
汇总报告列出可运行子集与局限。单元测试的合成解析样例只证明测试代码行为，
永远不作为 DeepSeek 或 Benchmark 成绩。

## 运行方式

1. 解压 zip
2. 进入 `可执行代码交付包\AgentGuard-Windows-x64\`
3. 双击 `Start-AgentGuard.cmd`（离线演示，无需安装环境、无需联网）
4. 浏览器访问 http://127.0.0.1:18765
